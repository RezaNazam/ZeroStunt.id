## 4. AUTHENTICATION FLOW (ACTUAL)

### Registration (AuthController::register)
```
User POST /auth/register
    ↓
Validasi username & password
    ↓
Check username sudah ada?
    ↓
Hash password + insert ke `users` table
    ↓
Redirect ke /auth/login dengan success message
```

### Login (AuthController::login)
```
User POST /auth/login
    ↓
Cari user di DB via User::findByUsername()
    ↓
Verify password vs stored hash
    ↓
Set session: user_id, username, role
    ↓
Redirect ke /dashboard
```

### Session Check
```
DashboardController::index()
    ↓
Cek $_SESSION['user_id'] ada?
    ↓
Jika belum, redirect /auth/login
    ↓
Cek profil lengkap via User::isProfileComplete()?
    ↓
Jika Ibu/Petani belum complete, redirect /master/[role]/create
    ↓
Render dashboard sesuai role
```

## 8. KEY CODE PATTERNS (ACTUAL IMPLEMENTATION)

### Database Connection Pattern (config/database.php)
```php
$koneksi = mysqli_connect($host, $user, $pass, $db);
// Global variable $koneksi, diakses di models via: global $koneksi;
```

### Model Pattern (User.php)
```php
class User {
    protected $db;
    
    public function __construct() {
        global $koneksi;
        $this->db = $koneksi;
    }
    
    public function findByUsername($username) {
        $stmt = mysqli_prepare($this->db, "SELECT * FROM users WHERE username = ?");
        mysqli_stmt_bind_param($stmt, 's', $username);
        mysqli_stmt_execute($stmt);
        return mysqli_fetch_assoc(mysqli_stmt_get_result($stmt));
    }
    
    public function create($username, $password, $role) {
        $hash = password_hash($password, PASSWORD_BCRYPT);
        $stmt = mysqli_prepare($this->db, "INSERT INTO users (...) VALUES (?, ?, ?)");
        mysqli_stmt_bind_param($stmt, 'sss', $username, $hash, $role);
        return mysqli_stmt_execute($stmt);
    }
}
```

### Controller Pattern (MasterController.php)
```php
class MasterController {
    public function createIbu() {
        // 1. Check login & role
        if (empty($_SESSION['user_id']) || $_SESSION['role'] !== ROLE_IBU) {
            header('Location: /auth/login');
            exit;
        }
        
        // 2. Prepare data (if needed)
        $gudangs = (new Gudang())->all();
        
        // 3. Render view
        require '../views/master/ibu/create.php';
    }
    
    public function storeIbu() {
        // 1. Check login
        if (empty($_SESSION['user_id'])) {
            header('Location: /auth/login');
            exit;
        }
        
        // 2. Check method
        if ($_SERVER['REQUEST_METHOD'] === 'POST') {
            // 3. Sanitize input
            $nik = trim($_POST['nik_ibu'] ?? '');
            $nama = trim($_POST['nama_ibu'] ?? '');
            
            // 4. Validate
            if ($nik === '' || $nama === '') {
                $_SESSION['error'] = 'NIK dan Nama wajib diisi.';
                header('Location: /master/ibu/create');
                exit;
            }
            
            // 5. Save to DB
            $ibuModel = new Ibu();
            if ($ibuModel->create($id_ibu, $nik, $nama, ...)) {
                $_SESSION['success'] = 'Profil berhasil disimpan.';
                header('Location: /dashboard');
                exit;
            }
            
            // 6. Error handling
            $_SESSION['error'] = 'Gagal menyimpan profil.';
            header('Location: /master/ibu/create');
            exit;
        }
    }
}
```

### Auth Helper Pattern (AuthHelper.php)
```php
class AuthHelper {
    public static function login($username, $password) {
        $user = /* query dari DB */;
        if ($user && password_verify($password, $user['password'])) {
            session_regenerate_id(true);
            $_SESSION['user_id'] = $user['id_user'];
            $_SESSION['username'] = $user['username'];
            $_SESSION['role'] = $user['role'];
            return true;
        }
        return false;
    }
}
```

### RBAC Helper Pattern (RBACHelper.php)
```php
class RBACHelper {
    private static $permissions = [
        ROLE_ADMIN => ['dashboard.admin', 'master.*', ...],
        ROLE_KADER => ['dashboard.kader', 'master.read', ...],
        // ...
    ];
    
    public static function require_role($required_role) {
        if ($_SESSION['role'] !== $required_role) {
            http_response_code(403);
            die("403 - Access Denied");
        }
    }
}
```

## 10. CONVENTION & PATTERN YANG SUDAH DITERAPKAN

### File Naming
```
✅ Controllers: [Entity]Controller.php (AuthController, MasterController)
✅ Models: [Entity].php (User, Ibu, Gudang, PetaniLokal)
✅ Views: /master/[entity]/[action].php (ibu/create.php, gudang/edit.php)
✅ Routes: /[entity]/[action] (/master/ibu/create, /master/gudang/edit)
```

### Method Naming in Controller
```
✅ GET methods: [entity]list / [action][Entity] (indexGudang, createIbu)
✅ POST methods: store[Entity] / update[Entity] / delete[Entity] (storeGudang, updateGudang)
✅ Pattern: get → render form | post → process & redirect
```

### View Structure
```php
// views/master/gudang/index.php
<?php require_once '../layout/base.php'; ?>

<div class="container">
    <h1>Daftar Gudang</h1>
    
    <?php if (isset($_SESSION['success'])): ?>
        <div class="success"><?= $_SESSION['success']; unset($_SESSION['success']); ?></div>
    <?php endif; ?>
    
    <a href="/master/gudang/create">+ Tambah Gudang</a>
    
    <table>
        <tr>
            <th>Nama</th>
            <th>Jenis</th>
            <th>Aksi</th>
        </tr>
        <?php foreach ($gudangs as $g): ?>
            <tr>
                <td><?= $g['nama_gudang'] ?></td>
                <td><?= $g['jenis_gudang'] ?></td>
                <td>
                    <a href="/master/gudang/edit?id=<?= $g['id_gudang'] ?>">Edit</a>
                    <a href="/master/gudang/delete?id=<?= $g['id_gudang'] ?>">Delete</a>
                </td>
            </tr>
        <?php endforeach; ?>
    </table>
</div>
```

### Session Management
```php
// Set success message
$_SESSION['success'] = 'Data berhasil disimpan.';

// Display & clear
<?php if (isset($_SESSION['success'])): ?>
    <div><?= $_SESSION['success']; ?></div>
    <?php unset($_SESSION['success']); ?>
<?php endif; ?>

// Logout
session_unset();
session_destroy();
```
